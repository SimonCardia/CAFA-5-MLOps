[IMPLEMENTATION TASK]

- map output indices to GO terms via term_names.npy
- sort predictions by score descending
- return only Top-k results


[IMPLEMENTATION TASK]
Input validation must:
- require exactly one embedding
- verify embedding length == 1280
- reject non-numeric values
- cast values to float32
- reshape input to (1, 1280) before inference
- reject batch input in the MVP


[IMPLEMENTATION TASK]
API error handling must:
- return HTTP 400 for invalid client input
- return HTTP 500 for model loading or inference failures
- use clear and short error messages
- keep health endpoint behavior separate from predict endpoint behavior


[IMPLEMENTATION TASK]
Model loading must:
- happen at API startup
- read artifacts only from /app/models
- expose model_loaded status to /health
- expose model_version if available
- prevent successful /predict execution when the model is unavailable


[IMPLEMENTATION TASK]
MLflow integration must:
- log inference metadata only
- be best effort / non-blocking
- not prevent successful API responses if MLflow is unavailable
- log model_version, top_k, runtime, and prediction_count
- optionally log request_id if present
